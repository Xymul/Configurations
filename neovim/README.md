# neovim configurations

## 说明

一个简易的neovim插件配置，基于lazy.nvim，包含自动补全、高亮、LSP/LspConfig、statusbar增强、Colorscheme、性能监控。

只进行了极简的配置，大部分基础行为和功能没有变动。

由于该仓库仅面向本人使用，所以暂时没有设置Options以供方便修改功能。
